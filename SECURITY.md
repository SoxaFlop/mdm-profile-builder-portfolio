# Security policy

This repository contains demonstration source code only. Do not submit real Jamf School credentials, tenant identifiers, Wi-Fi passwords, exported `.mobileconfig` profiles, device records, organisation names or licence-signing keys in issues or pull requests.

Optional credentials entered while running the app are stored through macOS Keychain. The portfolio build contains no live tenant connection, deployment configuration or licensing backend. Use an isolated test tenant for any integration testing, and review every generated profile before importing or deploying it.

If you find a security issue, contact the repository owner privately. Do not include live credentials or device data in a public report.
